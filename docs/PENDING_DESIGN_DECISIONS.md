## D-001：增强页面结构的视觉冲击

**状态：待确认 / 暂不实施**

当前页面整体采用规则、对称的模块组织：标题 → 网格 → 标题 → 网格。优点是稳定、清晰，缺点是摄影 / 影视类页面的视觉节奏可能偏平。

如果完成文字调整后仍觉得视觉冲击不足，再从以下方向中选择，不建议一次全部实施。

### 方案 A：建立三档内容宽度

- 文字内容：约 900–1100px
- 常规内容：约 1280–1440px
- 核心影像：约 90vw，允许突破常规内容宽度

目的：让影像与文字产生明显尺度差，而不是所有区域都锁在相同宽度。

### 方案 B：作品区引入非均匀卡片

保留整体内容顺序，但让少量核心作品占 2 列或更大的展示面积，其余作品维持常规卡片。

目的：制造视觉焦点，避免四张图片权重完全相同。

### 方案 C：摄影师区域改为非对称人物构图

候选结构：一侧使用更大人物照片，另一侧放姓名、职位、简介、经历等信息；下一位摄影师可镜像排列。

目的：加强人物专业形象和杂志式版面感。

### 方案 D：调整 Section 节奏

不是简单增加间距，而是让不同模块拥有不同的上下留白和标题位置，例如部分标题靠左、部分居中，核心图片区更贴近标题或主动拉开。

目的：减少“每一屏结构完全一样”的模板感。

## 重新评估条件

先完成并观察当前文字体系。只有出现以下情况时，再进入结构方案评审：

1. Hero 字号放大后仍然缺少第一屏冲击力；
2. Section 标题加强后，作品区依然显得过于平均；
3. 摄影师模块仍然像普通企业官网而不是专业影像工作室；
4. 1440px / 1920px 桌面屏下页面仍有明显“内容缩在中间”的感觉。

## 实施原则

- 一次只验证一个结构变量。
- 优先保留当前已确认的视觉元素。
- 不因为 Demo 阶段提前引入复杂交互。
- 每次结构调整都应能独立回退和比较。

## D-002：作品详情展示方式

**状态：已确认 / 已实施**

当前首页作品卡片只负责展示，不在 Demo 阶段伪造点击后的详情行为。

后续优先评估以下方案：

### 推荐方向：独立作品详情页

路径示例：

```text
/works/project-slug
```

详情页可承载：

- 项目 Hero / 封面
- 项目名称、分类、简介
- 多张大图
- 视频
- 客户 / 团队 / 时间等项目字段
- 上一个 / 下一个项目

优点：更适合摄影、影视作品的沉浸式呈现，也更方便未来 CMS 维护和 SEO。

### 可选增强：Lightbox 快速预览

首页点击单张图片时，可先打开轻量大图预览；需要完整浏览项目时再进入详情页。

### 暂不推荐：所有内容塞进普通 Modal

普通弹框适合单图预览，但当一个项目包含多图、视频、项目介绍后承载能力不足，也不利于 URL 分享和独立收录。

### 决策时机

已根据当前需求落地独立作品详情页。首页作品卡片进入 `/works/{slug}`，详情页包含项目 Hero、元信息、项目影像和上下篇导航；未配置详情图片集的作品暂时使用封面作为默认影像。

## D-004：首页首屏视觉原则

**状态：已确认 / 已实施**

首页第一屏是全站最重要的视觉入口，后续调整遵循：

1. Header 采用叠加在 Hero 图片上的半透明玻璃效果，不再作为独立黑色横条切断图片。
2. Hero 图片从页面最顶部开始，穿透 Header，形成一个完整视觉画面。
3. 播放按钮、主标题、英文副标题、栏目 Tab、01–04 栏目介绍属于同一个纵向视觉组。
4. 01–04 不再绝对定位贴底，避免标题区与介绍区产生巨大断层。
5. Header 在页面顶部保持较轻透明度；滚动后自动加深并增强模糊，保证导航可读性。
6. 首屏优先保证视觉冲击和层级，不使用后台管理系统式的重边框 Tab 视觉。
