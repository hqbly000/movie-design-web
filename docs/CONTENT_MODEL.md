## 后台 UX 原则

未来后台不要求运营人员理解文件格式、压缩率、CDN、AVIF/WebP、HLS 等技术概念。

上传原素材后由系统负责媒体处理；运营人员只管理“内容本身”。


## 首页栏目模型（已确认）

首页 Hero 的四个入口不是普通标签，而是一级内容栏目：

```text
Channel
├─ id
├─ label
├─ meta
├─ features[4]   # 当前栏目的 01–04 介绍
└─ works[]       # 当前栏目关联的作品
```

当前 Demo 栏目：

- video：视频 / 短片
- expert：专家
- popular：科普
- 10h：10H

作品通过 `channelId` 关联栏目。未来 CMS 中应允许运营人员选择栏目并维护栏目介绍、排序和关联作品。
