描边字怎么做的

  • 单层 <text>：主体 300px 走 stroke: url(#goldStroke) 竖向金渐变（#F7E6BD → #E8C77A → #C49A4A → #8F6A2C）。外圈幽灵描边已删除 —— 前景本身就是金线，再套一层线只剩脏
  • 间距是裁出来的，不是调 gap 调出来的：SVG getBBox() 对 <text> 返回的是字体行盒（Noto Sans SC 约 1.45em）而不是字形墨迹，所以旧 viewBox 0 0 300 210 里"9"实际只占 110×161，左右各空 95px。改用 canvas measureText().actualBoundingBox* 量到 300px 下墨迹 159×234，viewBox 收成 -88 -234 176 240，再把 .emblem-stroke 的 gap 从 20 降到 6
  • 逐笔勾出 = stroke-dasharray / stroke-dashoffset 从 1500 收到 0，4.4s 起笔延后 0.9s，缓动 cubic-bezier(.33,.02,.2,1)（去掉原来 .16,.84 那种"甩出去"的急收）；落金 + 辉光推到 5s 才开始，整段约 7s 走完
  • 勾完再接 2s 把 fill 淡入到 rgba(196,154,74,.13)，同时 drop-shadow(0 0 26px) 起辉光 —— 线框数字没有实心色块压场，辉光比之前更关键
  • SINCE 2017 竖排取 V2（writing-mode: vertical-rl + text-orientation: mixed，拉丁侧倒自上而下）。注意 flex 要写 flex-direction: row，vertical-rl 下 row 才是自上而下，写 column 会横着排
  • SINCE 2017 提亮到 #E8C77A，「年」改用 Noto Serif SC 与左侧标题同源，替掉原来的黑体 #1F2329

三个要拍板的点

  • 计数动画要不要留：现在 useCountUp 是 1→9 跳数字，和逐笔勾出是两套语言、 放一起会打架。建议去掉计数，只留描边；数字保持静态 9，靠描边动画承担"活"的部分
  • dasharray 要随位数变：300px 下单个数字轮廓周长约 1440，两位数约 2880。实现时按 String(years).length 给系数（位数 × 1500）即可，不然两位数时后半段 画不完。宁大勿小：偏大只是结尾空转一小段，偏小则永远缺一截
  • 按钮选哪个：① 金线描边最贴这套暗调；② 象牙实心是全站已有 token， 和荣誉/首屏的按钮体系同源；③ 橙色实心保持原样。选 ③ 的话这一屏就还是有一块橙色斑
