# 2026-08-26

## 作品展示区块改造（两轮）

项目：movie-design-web（Astro 单页深色摄影工作室 Demo）。作品展示由 `Works.astro` + `global.css` 的 `.work-*` + `index.astro` 内联脚本驱动。

### 第一轮（已废弃）
- 用户原先对 4 列等宽横滚 + 栏目筛选只耦合在 Hero 的方案不满意。
- 我做过一版「编辑式 Bento 网格 + 区块内筛选 Pill」改造稿（画布 `作品展示改造方案`），并开了分支 `feature/works-bento-redesign`。
- 用户已退回 main，未采用 Bento 方向。

### 第二轮（当前）
- 用户要「仍是轮播图，但有层级」→ 明确为 **中心聚焦 Cover Flow**：焦点作品居中放大、两侧卡片缩小变暗 + 轻微 3D 旋转层叠（z 轴景深）。
- 新分支 `feature/works-coverflow`（基于 main）。
- 改动文件：
  - `src/components/Works.astro`：新增区块内栏目 Pill（`data-channel-tab`）、`.work-stage`/`.work-track` 结构与每张卡 `data-work-channel`、`.work-gallery` 上 `data-default-channel`。
  - `src/styles/global.css`：替换 `.work-gallery/.work-track/.work-card` 为封面流（absolute 居中 + perspective + 由 JS 设置 transform/opacity/zIndex），新增 `.work-filters/.work-pill/.work-tag/.work-cta`；响应式改 `.work-stage` 高度，去掉失效的 `grid-auto-columns`。
  - `src/pages/index.astro`：给 `Works` 传 `channels={page.hero.channels}`；把旧 `activateChannel` 横滚逻辑替换为统一的 `setChannel`（Hero Tab 与作品 Pill 共用，同时驱动 Hero 特性面板 + 封面筛选），并加封面流控制器（layout/go/点击侧卡聚焦/键盘左右/进入视口重排）。
- 关键设计：首屏默认显示 `video` 栏目 6 件，焦点卡居中放大、其余按距离缩小压暗后退；点侧卡即切换焦点，圆形上一件/下一件按钮驱动 `go()`。
- 修复原 bug：旧方案作品区无独立筛选器、与 Hero Tab 不联动；现统一 `setChannel` 同步两边状态。
- 验证：Node 22 构建通过（生成 index.html + 24 个作品详情页）；`npm run build` 末尾的 `safe-delete` 报错是 WorkBuddy 沙箱回收 `dist/pages/*.mjs` 失败，不影响产物。本地 dev `http://localhost:4321/` 已起。

### 第三轮（交互增强，第二轮延续）
- 用户反馈：cover flow 仅靠左右圆形按钮切换"有点傻、不符合使用习惯"。
- 新增最直觉的手势交互（`src/pages/index.astro` 控制器 + `src/styles/global.css`）：
  - **指针拖拽 / 触摸滑动**：pointerdown/move/up 跟手平移 `.work-track`（`translateX`），松手按位移阈值（首卡宽 *0.22）吸附到上/下一件，未超阈值则回弹；用 `setPointerCapture` 捕获指针。
  - **拖拽误触拦截**：拖拽后通过 capture 阶段 click 监听器拦截误触发的卡片点击（避免拖动焦点卡却进详情）。
  - **滚轮横向**：仅响应 trackpad 横向滑动（`|deltaX|>|deltaY|`）切卡并 `preventDefault`，纵向滚轮放行页面；加 320ms 节流锁。
  - 圆形按钮降为辅助，手势为主。
- CSS：`.work-track` 加 `touch-action:pan-y`（横向手势归我们、纵向放行页面）+ `cursor:grab`；`.work-track.is-grabbing` 时 `cursor:grabbing`。
- 验证：Node 22 构建无真实编译错误（bundle 含 `pointerdown`/`is-grabbing`）；本地 dev 仍在 `http://localhost:4321/`（HTTP 200，HMR 已生效）。
- 初始焦点微调：默认 `activeIndex` 改为第 3 张（`INITIAL_FOCUS=2`，clamp 到栏目长度-1），使左侧露出两张、构图平衡；切换栏目时亦沿用该默认焦点。
